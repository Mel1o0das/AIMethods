## Проверяемая логика сценариев

Тесты подтверждают:

1. Каталог фильтрует и пагинирует детерминированные данные, а главная передаёт строку поиска в `/objects`.
2. Примыкающие полуоткрытые интервалы `[start, end)` допустимы; пересечение отклоняется без изменения количества заявок.
3. Две почти одновременные отправки одинакового интервала дают ровно одну созданную запись и одну ошибку.
4. При конфликте UI сохраняет интервал и число гостей, не закрывает модальное окно и снова включает кнопку.
5. Отмена владельцем освобождает слот, после чего тот же интервал можно занять повторно; чужая и завершённая заявки не отменяются.
6. Страница собственных заявок скрывает действие отмены у завершённой записи.

## Доказательство изоляции Mock-режима

`getBookingDataSource()` выбирает только один адаптер. При `NEXT_PUBLIC_DATA_MODE=mock` каталог, типы, статусы, занятость и заявки обращаются к `mockDataSource`; API-only авторизация, пользователи и административные мутации вызывают `requireApiMode` или эквивалентную блокировку до `fetch`.

В тестах глобальный `fetch` заменяется падающей заглушкой. Все 12 тестов Mock-источника, включая каталог, создание, конфликт, двойную отправку, отмену и API-only операции, прошли с ожиданием `fetchSpy` равным нулю. Это автоматическое доказательство для покрытых путей, что запрос на `http://localhost:5260/api` или другой HTTP endpoint не отправлялся.

## Важные отладочные итерации

- Первый тест формы упёрся в особенности настоящих Ant Design portal/picker внутри jsdom. Тестовые подмены сузили только `Modal` и `DatePicker`; реальные `Form`, `Input` и `InputNumber` сохранены. Затем исправлено ожидание DOM-значения number input со строки на число/строковое представление. Финальный тест проходит.
- React lint выявил вычисление `Date.now()` во время render и синхронный state update внутри effect. Время открытия страницы стабилизировано в state, а загрузка API-сессии переписана на отменяемую асинхронную цепочку.
- Production build автоматически изменял `next-env.d.ts`; сгенерированный шум не оставлен в рабочем diff.
