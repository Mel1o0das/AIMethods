## Тесты и найденные ошибки

Добавлены 4 UI-теста:

1. Поиск на главной формирует URL каталога.
2. Поиск каталога меняет видимые Mock-объекты.
3. Пустая выдача показывает и выполняет «Сбросить фильтры».
4. Ошибка загрузки показывает retry; повторная попытка выводит карточку.

Важные итерации:

- ESLint обнаружил 2 ошибки `react-hooks/set-state-in-effect`; переходы loading перенесены из тела эффектов в обработчики.
- Первый UI-прогон обнаружил отсутствие автоматического cleanup DOM; добавлен явный cleanup.
- Empty-state имел две одинаковые кнопки сброса; устранено дублирование.
- Один параллельный прогон занял 5,16 с при лимите 5 с; assertions сохранены, test timeout увеличен до 10 с. Повторные полные прогоны прошли.
- При ревью обнаружено исчезновение поля поиска во время repeat loading; initial и repeat loading разделены, старые карточки при этом не показываются.
