# Промпт для v0 — концепция 1 «Природный минимализм»

Создай качественный интерактивный UI-прототип сервиса бронирования бань и глэмпингов **BookingService**. Это редизайн существующего Frontend на Next.js/React, а не новый бизнес-продукт. Язык всего интерфейса — русский, цены в ₽.

**Общий сценарий для сравнения трёх концепций:** пользователь открывает каталог объектов загородного отдыха, ищет подходящую баню или глэмпинг, просматривает характеристики, открывает детали и может выбрать интервал бронирования. Используй только локальные демонстрационные данные, не подключай API, платежи, регистрацию, реальные бронирования или внешние сервисы. Интерфейс должен быть адаптивным, пригодным для desktop 1440 px и mobile 390 px.

**Уникальная дизайн-концепция № 1: природный минимализм / editorial nature.** Атмосфера камерного загородного отдыха, без ощущения стандартного маркетплейса. Палитра: тёплый молочный фон #F7F4ED, тёмный хвойный #243E34, шалфейный #7B977F, натуральный песочный #D8C6AA. Много воздуха, спокойная типографика, мягко скруглённые фотографии, аккуратные тонкие разделители, качественные состояния hover/focus. Читабельность важнее декоративности.

**Композиция desktop:**
- Верхняя узкая навигация: BookingService, «Объекты», «Мои бронирования», «Войти».
- Широкий атмосферный hero-блок с фотографией природы и заголовком «Отдых, который хочется запомнить»; на переднем плане компактная полупрозрачная панель поиска с выбором «Все / Глэмпинги / Бани», датой или временем, количеством гостей и кнопкой «Найти».
- Ниже — заголовок «Выберите место для отдыха», небольшая строка фильтров-чипов («Все объекты», «Бани», «Глэмпинги», «До 10 000 ₽», «До 4 гостей») и **сеточный каталог карточек в три колонки** с крупными фотографиями.
- Карточка: название, тип, количество гостей, цена с правильной единицей «₽/ночь» или «₽/час», короткий факт об объекте, кнопка «Подробнее».
- По нажатию на карточку или «Подробнее» — эстетичная боковая панель деталей с фото, описанием, вместимостью, ценой и действием «Выбрать дату и время». Из неё открывается форма бронирования: начало, окончание, гости, комментарий; для бани — часы, для глэмпинга — даты проживания.
- Покажи небольшую заметку под выбором интервала: «Доступность уточняется перед подтверждением». При имитации занятого интервала — дружелюбное сообщение «Это время уже занято, выберите другое».

**Демонстрационные объекты (те же названия используй в других концепциях):** «Купольный домик у озера» (глэмпинг, 2 гостя, 8 500 ₽/ночь), «Баня на дровах» (баня, 6 гостей, 2 500 ₽/час), «Домик „Сосны“» (глэмпинг, 4 гостя, 11 000 ₽/ночь), «Баня „Лесная“» (баня, 4 гостя, 2 100 ₽/час), «Сфера среди сосен» (глэмпинг, 2 гостя, 9 200 ₽/ночь), «Баня у ручья» (баня, 8 гостей, 3 000 ₽/час). Данные вымышленные и нужны только для макета.

**Mobile:** hero не должен съедать весь экран; поиск компактный, фильтры раскрываются снизу, карточки в одну колонку, заметная кнопка бронирования. Нет горизонтального скролла.

**Поведение:** фильтры и вкладки реально меняют набор демонстрационных карточек; карточки открывают детали; форма показывает демонстрационную обработку обязательных полей; отображай loading, empty state и сообщение о конфликте только как состояния прототипа. Для доступности используй понятные подписи полей, видимый focus и достаточный контраст. Не добавляй карту, отзывы, онлайн-оплату, программу лояльности и выдуманные рейтинги. Визуально сосредоточься на каталоге и бронировании, а не на лендинге в целом.

Используй Next.js App Router + React + TypeScript для демонстрационного прототипа. Вывод должен быть пригоден для живого Preview в v0. Дизайн этой концепции не должен напоминать корпоративную таблицу или тёмный luxury-лендинг.
