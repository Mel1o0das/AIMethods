# Промпт для v0 — концепция 2 «Премиальный отдых»

Создай качественный интерактивный UI-прототип сервиса бронирования бань и глэмпингов **BookingService**. Это редизайн существующего Frontend на Next.js/React. Все надписи — на русском, цены в ₽. Прототип нужен для сравнения UI-концепций; не подключай API, авторизацию, базу данных, платежи или внешние сервисы. Используй локальные демонстрационные данные, адаптивный интерфейс для desktop 1440 px и mobile 390 px.

**Общий сценарий:** пользователь просматривает объекты загородного отдыха, фильтрует каталог, открывает карточку и выбирает даты/время для оформления заявки. По функциям концепция должна быть сравнима с двумя другими, но по композиции — заметно отличаться.

**Уникальная дизайн-концепция № 2: premium retreat / тёмный кинематографичный стиль.** Палитра: графит #171D1B, глубокий лесной #26352E, приглушённая медь #C7A67A, кремовый #EFE6D6. Большие выразительные фотографии домиков, вечерней бани, тёплого света; контрастная типографика с элегантными крупными заголовками. Избегай кричащего золота и декоративных эффектов, которые мешают чтению.

**Композиция desktop, принципиально не такая, как обычная карточная сетка:**
- Тёмная навигационная полоса с брендом BookingService, «Коллекция мест», «Бани», «Глэмпинги», «Мои бронирования», «Войти».
- **Split-screen hero:** слева крупный заголовок «Место, где время замедляется» с коротким описанием и кнопкой «Исследовать места»; справа — высокая атмосферная фотография со скруглением только в двух углах.
- Под hero — **горизонтальная коллекция крупных editorial-карточек**: одна акцентная большая карточка и две соседние меньшие, без стандартной трёхколоночной сетки. Под карточками — компактная полоска параметров и кнопка «Смотреть объект».
- Под коллекцией — понятная секция «Найти свой формат отдыха» с переключателем «Глэмпинги / Бани», фильтрами по гостям и цене и **вертикальным списком из широких строк**: фотография слева, характеристики по центру, цена и CTA справа.
- При выборе объекта открывается **полноэкранное detail-overlay или широкий drawer**, в котором слева галерея и описание, справа — фиксированная панель бронирования с датами/временем, гостями, ценой и основной кнопкой «Отправить заявку».
- В состоянии занятого слота явно показывай, что он недоступен, а после попытки выбора — «Выбранное время уже занято».

**Одинаковые демонстрационные объекты:** «Купольный домик у озера» (глэмпинг, 2 гостя, 8 500 ₽/ночь), «Баня на дровах» (баня, 6 гостей, 2 500 ₽/час), «Домик „Сосны“» (глэмпинг, 4 гостя, 11 000 ₽/ночь), «Баня „Лесная“» (баня, 4 гостя, 2 100 ₽/час), «Сфера среди сосен» (глэмпинг, 2 гостя, 9 200 ₽/ночь), «Баня у ручья» (баня, 8 гостей, 3 000 ₽/час). Все данные вымышлены.

**Mobile:** минималистичный тёмный header, компактный hero, горизонтальная прокрутка карточек только внутри подборки (не всей страницы), фильтры через понятную кнопку, вертикальный каталог, detail-overlay заполняет ширину экрана с фиксированной нижней кнопкой «Выбрать время».

**Поведение:** переключатель типов и фильтры меняют mock-каталог; открывается подробный просмотр; форма бронирования различает даты ночёвки для глэмпинга и часы для бани. Демонстрируй валидацию пустых/неверных полей и состояние конфликта. Добавь состояния loading и отсутствия результатов. Текст, поля и кнопки должны оставаться читаемыми на тёмном фоне, с видимым keyboard focus.

Не добавляй карту, отзывы, онлайн-оплату, программу лояльности, фальшивые оценки или backend. Используй Next.js App Router + React + TypeScript для прототипа. Ключевой акцент — премиальная атмосфера, асимметричная компоновка и крупные визуальные блоки, а не интерфейс интернет-магазина.
